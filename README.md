Простой прокси для определенных сайтов, без рекламы.
Управляйте прокси по списку доменов: направляйте через прокси только выбранные сайты или включите прокси для всех сайтов, кроме исключений.

Proxy Manager позволяет настроить адрес прокси и выбрать, для каких доменов он будет использоваться. В обычном режиме прокси применяется только к сайтам из основного списка. В режиме исключений прокси применяется ко всем сайтам, кроме доменов в списке исключений. Списки можно импортировать и экспортировать.

# Установка и использование Proxy Manager

Версия для Firefox: [Firefox Proxy Manager](https://github.com/abyss-soft/Firefox-proxy-manager)

## Шаг 1: Скачать расширение с GitHub

1. Скачайте (https://github.com/abyss-soft/Chrome-proxy-manager) репозиторий.
2. Распакуйте загруженный архив в удобное место на компьютере. После распаковки папка должна содержать такие файлы и папки:
   ```
   Chrome-proxy-manager/
   ├── manifest.json
   ├── popup.html
   ├── popup.js
   ├── background.js
   ├── AddData/
   └── icon-файлы
   ```

## Шаг 2: Включение режима разработчика в Chrome

1. Откройте браузер Chrome.

2. Перейдите на страницу **Расширения**, набрав в адресной строке: `chrome://extensions/`

3. Включите **Режим разработчика** (Developer mode) в правом верхнем углу страницы.

## Шаг 3: Установка распакованного расширения

1. Нажмите на кнопку **Загрузить распакованное расширение** (Load unpacked).
2. Выберите папку, в которую распаковали файлы расширения (например, `extension-folder`).
3. Chrome загрузит расширение, и оно появится в списке установленных расширений.

## Шаг 4: Использование расширения

1. Нажмите на иконку вашего расширения в панели инструментов Chrome.

2. В интерфейсе расширения вы можете:
- Включить/выключить прокси.

- Добавлять нужно домен без протокола и пути, например `example.com` или `www.example.com`.

- В обычном режиме через прокси идут только сайты из основного списка, остальные открываются напрямую.

- Если включить режим исключений, через прокси идут все сайты, кроме перечисленных в списке исключений.

- Настроить параметры прокси-сервера в формате `схема://хост:порт` и нажать «Сохранить».
3. Списки и переключатели сохраняются автоматически. Адрес прокси сохраняется после нажатия «Сохранить» и применяется вместе с выбранным режимом.

## Шаг 5: Обновление расширения (при выходе новой версии)

Когда в GitHub появится новая версия, скачайте и распакуйте её, как описано выше.

Теперь расширение установлено и готово к использованию!
